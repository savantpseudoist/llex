# Contributing to LLex

Thanks for your interest in improving LLex.

## Before you start

- Open an issue for bugs or feature ideas before larger changes.
- Keep pull requests focused and small.
- Be respectful and follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Local setup

1. Create and activate a virtual environment.
2. Install dependencies with:
   - `pip install -e .`
3. Run the app with:
   - `python -m llex.main`

## Pull request checklist

- [ ] Describe the problem and the change clearly.
- [ ] Keep backward compatibility unless discussed.
- [ ] Update README/docs if behavior changes.
- [ ] Ensure the project still runs locally after changes.
